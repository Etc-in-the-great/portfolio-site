# User Workflow Rules

## My Level And Goals

- Explain things in beginner-friendly language.
- Help me build a personal portfolio first, then AI tool websites and small Python utilities.
- Prefer React, Next.js, Tailwind CSS, and Vercel for frontend work.
- Keep the project clean enough to show in a portfolio.

## Before Editing

- Inspect files before changing them.
- Briefly explain the plan before editing.
- Avoid changing many unrelated files in one pass.
- Do not secretly add dependencies.
- Before adding a dependency, explain why it is needed.

## Debugging

- Read the error and identify the likely cause before reinstalling anything.
- Prefer one focused fix at a time.
- Run `npm run lint` and `npm run build` after meaningful changes when practical.

## After Editing

- Tell me which files changed.
- Tell me what commands were run and whether they passed.
- Give me the next small learning step.
