# Project Skill Documents

These are project-level skill documents for AI collaboration in this workspace.

They are written in the same general shape as Codex skills, with each skill living in its own folder and using a `SKILL.md` file.

## Current Skills

- `product-planning`: turn vague ideas into MVP slices.
- `implementation-review`: review changes before finishing.
- `portfolio-polish`: improve portfolio product feel without over-scoping.
- `next-portfolio-page`: build or refine portfolio routes and project pages.
- `ai-prototype-documentation`: keep AI prototypes honest, clear, and portfolio-ready.
- `python-utility-safety`: design Python utilities with safe dry-run defaults and clear terminal evidence.

## How To Use

Ask Codex to use one explicitly, for example:

- `Use the product-planning skill in .codex/skills before implementing this idea.`
- `Use implementation-review to review the last change.`
- `Use portfolio-polish to improve this project page without adding new features.`
- `Use next-portfolio-page before adding a new project route.`
- `Use python-utility-safety before changing a file operation script.`

## Important Limit

This folder documents project skills. It may not be auto-discovered as official runtime skills unless installed or exposed through Codex's configured skill system.
