## Project Summary

AI Learning System 是一个基于 Portfolio Site 逐步演进的 AI 辅助学习与项目管理系统。当前已完成作品集展示、AI Study Assistant、DeepSeek API 接入、Learning History 本地保存原型、Python Study Utilities 和 Batch File Renamer dry-run 工具。后续计划在期末后继续推进 Database Design、Project Management Module 和学习记录分析能力。

---

## Main Modules

- Portfolio Site：项目统一展示入口，用于呈现学习路线、作品集和 case study。
- AI Study Assistant：把学习笔记生成 Summary、Key Points 和 Review Questions。
- DeepSeek API Integration：通过服务器端 API Route 调用 DeepSeek，避免在前端暴露 API Key。
- Learning History Module：使用 localStorage 保存生成后的学习记录，并支持 History、Detail 和 Delete。
- Python Study Utilities：学生学习工具箱方向，用 Python 做文件整理和学习资料自动化。
- Batch File Renamer：已完成 dry-run Python script，可安全预览批量重命名结果。
