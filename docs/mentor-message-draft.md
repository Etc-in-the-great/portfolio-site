# 导师沟通版项目摘要

付老师您好，我目前在做一个叫 **AI Learning System** 的项目，想把它作为后续软件开发方向的长期项目继续完善。

这个项目最开始是一个个人 Portfolio Site，现在已经逐步扩展成一个 AI 辅助学习与项目管理系统的原型。当前已经完成的部分包括：作品集首页、项目 case study、AI Study Assistant、DeepSeek API 接入、Learning History 学习记录模块，以及一个 Python Study Utilities 工具方向。

目前 AI Study Assistant 可以把学习笔记生成 Summary、Key Points 和 Review Questions。Learning History 模块可以把生成后的学习记录保存到本地，并支持 History Page、Note Detail 和 Delete Note。Python Study Utilities 里也做了一个 Batch File Renamer 的 dry-run 脚本，用来安全预览批量文件重命名结果。

我现在还没有急着接数据库和用户系统，而是先把产品流程、页面结构和数据字段设计清楚。下一步我想围绕数据库设计继续推进，比如学习记录表、项目记录表、标签表，以及后续的 Project Management Module。

我觉得这个项目比较适合软件开发方向，是因为它不只是一个单独的 AI 页面，而是可以继续扩展成包含前端、后端、数据库、AI API、项目管理和学习记录分析的完整系统。后续如果作为毕设方向，也可以逐步加入用户管理、数据持久化、AI 生成 README、学习分析等功能。

想请老师帮我看看这个方向是否适合作为后续毕设或长期项目继续推进，也希望老师能给我一些关于系统结构、数据库设计和软件开发方向的建议。
